### 🟦 PROMPT 2 — Supabase Schema

```
Create backend/supabase/schema.sql

Write this SQL exactly:

CREATE TABLE incidents (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  title TEXT NOT NULL,
  service TEXT NOT NULL,
  severity TEXT CHECK (severity IN ('SEV-1','SEV-2','SEV-3','SEV-4')),
  status TEXT DEFAULT 'open' CHECK (status IN ('open','diagnosing','remediating','resolved')),
  symptoms JSONB,
  root_cause TEXT,
  confidence_score FLOAT DEFAULT 0,
  recommended_fix TEXT,
  blast_radius TEXT,
  mttr_seconds INT,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  resolved_at TIMESTAMPTZ
);

CREATE TABLE fixes (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  incident_id UUID REFERENCES incidents(id) ON DELETE CASCADE,
  action TEXT NOT NULL,
  success BOOLEAN,
  side_effects TEXT,
  applied_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE timeline_events (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  incident_id UUID REFERENCES incidents(id) ON DELETE CASCADE,
  event_type TEXT CHECK (event_type IN ('alert','deploy','log','metric','ai_diagnosis','human_action','resolution')),
  description TEXT,
  raw_data JSONB,
  timestamp TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX idx_incidents_service ON incidents(service);
CREATE INDEX idx_incidents_created ON incidents(created_at DESC);
CREATE INDEX idx_timeline_incident ON timeline_events(incident_id);

ALTER TABLE incidents ENABLE ROW LEVEL SECURITY;
ALTER TABLE fixes ENABLE ROW LEVEL SECURITY;
ALTER TABLE timeline_events ENABLE ROW LEVEL SECURITY;

CREATE POLICY "public_all_incidents" ON incidents FOR ALL USING (true) WITH CHECK (true);
CREATE POLICY "public_all_fixes" ON fixes FOR ALL USING (true) WITH CHECK (true);
CREATE POLICY "public_all_timeline" ON timeline_events FOR ALL USING (true) WITH CHECK (true);

-- Enable realtime
ALTER PUBLICATION supabase_realtime ADD TABLE incidents;
ALTER PUBLICATION supabase_realtime ADD TABLE timeline_events;
```

### 🟦 PROMPT 3 — Hindsight Memory Client

```
Create backend/src/memory/hindsight.js

Import axios. Use:
- const API_URL = process.env.HINDSIGHT_API_URL || 'https://api.hindsight.vectorize.io'
- const API_KEY = process.env.HINDSIGHT_API_KEY

Create an axios instance with Authorization: Bearer ${API_KEY} and Content-Type: application/json.

Export four async functions with try/catch (on error, log '[HINDSIGHT ERROR]' and return safe defaults):

1. retainIncident(incident, fixOutcome)
   - Build a natural-language memory string:
     "Incident on ${service}: ${title}. Severity ${severity}. Symptoms: ${JSON.stringify(symptoms)}. Root cause: ${root_cause}. Fix applied: ${fixOutcome.action}. Success: ${fixOutcome.success}. Side effects: ${fixOutcome.side_effects || 'none'}. MTTR: ${mttr_seconds}s."
   - POST /v1/retain with { bank_id: `sre-${service}`, content, context: 'incident_resolution', timestamp: new Date().toISOString(), metadata: { incident_id, service, success } }
   - Return response.data

2. recallSimilarIncidents(symptoms, service)
   - query = `Incident with symptoms: ${JSON.stringify(symptoms)} on service ${service}`
   - POST /v1/recall with { bank_id: `sre-${service}`, query, limit: 5 }
   - Return response.data.memories || []

3. reflectOnFixes(service)
   - POST /v1/reflect with { bank_id: `sre-${service}`, query: 'What fixes have worked best for incidents on this service?' }
   - Return response.data || {}

4. storeConversation(incidentId, messages)
   - POST /v1/retain with { bank_id: 'sre-conversations', content: JSON.stringify(messages), context: 'incident_conversation', metadata: { incident_id } }
   - Return response.data

On any failure, return [] for recall, {} for reflect/store, null for retain.
```

### 🟦 PROMPT 6 — Diagnose Agent (Core Intelligence)

```
Create backend/src/agents/diagnose.js

Import OpenAI, and from ../memory/hindsight.js import recallSimilarIncidents, reflectOnFixes.
From ../tools import getRecentDeploys, getLogs, getMetrics.

Export async function diagnoseIncident(incident)
- Input: incident object with { id, service, symptoms, severity, title }

Step 1 — Parallel fetch:
const [deploys, logs, metrics, pastIncidents, fixInsights] = await Promise.all([
  getRecentDeploys(incident.service),
  getLogs(incident.service, incident.symptoms),
  getMetrics(incident.service),
  recallSimilarIncidents(incident.symptoms, incident.service),
  reflectOnFixes(incident.service)
]);

Step 2 — Build memory context string:
If pastIncidents.length > 0: "SIMILAR PAST INCIDENTS (Hindsight memory):\n" + each memory's content as a bullet
Else: "No similar past incidents found."

Step 3 — Call OpenAI gpt-4o with response_format json_object.

System prompt:
"You are a Senior SRE with deep memory of past incidents. Use FRESH SIGNALS for evidence and PAST INCIDENTS as learned experience. Return JSON with keys: root_cause (string, cite specific evidence), confidence_score (0-100 int), recommended_fix (string, a specific action/command), blast_radius (string, what will be affected + estimated recovery time), evidence (array of 3-5 strings), similar_past_incident_ids (array of referenced memory IDs)."

User prompt includes:
- Incident: service, severity, title, symptoms
- Fresh signals: deploys, logs (first 10 lines), metrics
- Memory: pastIncidents list + fixInsights

Step 4 — If pastIncidents.length > 0, add +10 to confidence_score (cap at 95).

Step 5 — Return parsed JSON.
```

### 🟦 PROMPT 7 — Remediate Agent (Closes the Loop)

```
Create backend/src/agents/remediate.js

Import supabase client. Create a supabase service-role client at top of file using process.env.SUPABASE_URL and process.env.SUPABASE_SERVICE_KEY.
Import retainIncident from '../memory/hindsight.js'.

Export async function proposeRemediation(incidentId, diagnosis):
- Insert timeline_event: { incident_id, event_type: 'ai_diagnosis', description: `AI diagnosis: ${diagnosis.root_cause}`, raw_data: diagnosis }
- Update incidents row: status='diagnosing', root_cause, confidence_score, recommended_fix, blast_radius
- Return { requires_approval: true, action: diagnosis.recommended_fix, confidence: diagnosis.confidence_score }

Export async function executeRemediation(incidentId, action, approvedBy):
- Insert into fixes: { incident_id, action, applied_at: now }
- Insert timeline_event: { incident_id, event_type: 'human_action', description: `${approvedBy} approved: ${action}` }
- Update incidents: status='remediating'
- await new Promise(r => setTimeout(r, 2000))
- success = Math.random() < 0.9
- Update fixes row: success, side_effects: success ? null : 'Temporary latency spike during restart'
- Return { success, side_effects }

Export async function verifyRecovery(incidentId):
- await new Promise(r => setTimeout(r, 5000))
- Fetch incident row
- Compute mttr_seconds = (Date.now() - new Date(incident.created_at)) / 1000
- Update incidents: status='resolved', resolved_at=NOW(), mttr_seconds
- Insert timeline_event: { incident_id, event_type: 'resolution', description: `Recovered in ${Math.round(mttr_seconds)}s` }
- Fetch fixes row (latest) for this incident
- Call retainIncident(updatedIncident, { action: fix.action, success: fix.success, side_effects: fix.side_effects }) ← CRITICAL
- Return { recovered: true, mttr_seconds }

### 🟦 PROMPT 8 — Backend Routes

```
Create backend/src/routes/incidents.js

Setup Express router. Create supabase service client at top.

GET / — list all incidents ordered created_at DESC, limit 50
GET /:id — fetch incident + timeline_events + fixes for that id, return { incident, timeline, fixes }
POST /:id/approve — body { action, approvedBy } → call executeRemediation then verifyRecovery, return both results
GET /:id/similar — fetch incident, call recallSimilarIncidents(symptoms, service), return { memories }
GET /:id/postmortem — 
  1. Fetch incident, timeline_events, fixes
  2. Call recallSimilarIncidents for related
  3. Call gpt-4o with system prompt:
     "You write blameless postmortems. Given incident data, timeline, fixes, and related past incidents, generate structured markdown with sections: ## Summary, ## Impact, ## Timeline, ## Root Cause, ## Resolution, ## What Went Well, ## Action Items (3-5 concrete), ## Related Incidents. Cite evidence. No blame."
  4. Return { markdown, incident, related: memories }

Create backend/src/routes/chaos.js

POST /trigger — body { service, scenario }
- Generate title based on scenario (e.g., 'DB pool exhaustion on payment-api')
- Generate symptoms JSON based on scenario:
  - db_pool_exhaustion: { error_rate_spike: true, p99_latency: '>4s', log_pattern: 'HikariPool' }
  - memory_leak: { memory_growth: true, oom_risk: true }
  - bad_deploy: { recent_deploy: true, error_rate_spike: true }
  - network_partition: { timeouts: true, downstream_failures: true }
- Insert incident row with status='open', severity='SEV-2' (will be updated by triage)
- Insert timeline_event 'alert': `${service} alert fired: ${scenario}`
- Immediately (fire and forget, do not await for response):
  1. call triageAlert → update incident severity
  2. call diagnoseIncident → call proposeRemediation
- Return { incidentId }

Create backend/src/server.js

Import express, cors, dotenv/config, and the two routers.
